## 🔐 Authentication & Authorization Flow

```
┌────────────────────────────────────────┐
│  User makes request with token         │
│  GET /api/orders                       │
│  Authorization: Bearer {token}         │
└────────────────┬───────────────────────┘
                 │
                 ▼
┌────────────────────────────────────────┐
│  API: Extract & verify token           │
│  verifyToken(token)                    │
│  ├─ Valid?  ✓                          │
│  └─ Invalid? ✗ Return 401              │
└────────────────┬───────────────────────┘
                 │
                 ▼ (Token valid)
┌────────────────────────────────────────┐
│  API: Check user role                  │
│  decoded.role === "admin"              │
│  ├─ YES: isAdmin = true                │
│  └─ NO:  isAdmin = false               │
└────────────────┬───────────────────────┘
                 │
                 ▼
┌────────────────────────────────────────┐
│  Service: Build query based on role    │
│  ├─ Admin:   query = {} (see all)      │
│  └─ User:    query = { userId } (own)  │
└────────────────┬───────────────────────┘
                 │
                 ▼
            Return data
```
